# 🐍 Snake Game

Welcome to **Snake Game**, a classic game! Control the snake to eat food, grow longer, and avoid hitting the walls.🎮

---

## 🎮 Snake Game Features

- 🐍 **Snake Growth**: Eat red apples to grow the snake longer and score more points.
- ⏩ **Increasing Snake Speed**: The snake gets faster as your score increases.
- 🚫 **Wall Collisions**: The snake dies if it touches the screen border.
- 🏆 **Scoring System**: The score will increase by 1 each time the snake eats food.

## 🕹️ Controls

| **Key**         | **Action**               |
|------------------|--------------------------|
| `W` or `Up Arrow`   | Move Up                |
| `S` or `Down Arrow` | Move Down              |
| `A` or `Left Arrow` | Move Left              |
| `D` or `Right Arrow`| Move Right             |
| `R`            | Restart Game in **Game Over** screen               |

---

## 📜 How to Play

1. **Start the Game**:
   - Launch the game and the snake will start in the middle of the screen.

2. **Eat Food to Grow**:
   - Control the snake using `WASD` or `Arrows` and go for the red blocks, which causes the snake to grow longer and your score to increase.

3. **Things to Avoid**:
   - Don’t let the snake touch the screen borders, or the game will end.
   - You can't let the snake bump into itself.

4. **Improve**:
   - Go for a higher score everytime
